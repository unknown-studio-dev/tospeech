# Offline IPA dictionary artifact

`ipa.sqlite` is generated by `native/scripts/resources/build-ipa-dictionary.sh` from
pinned sources. The app reads this local SQLite resource only; it does not
download a dictionary at runtime.

| Layer (`source` column) | Accent | What it is | Licence |
| --- | --- | --- | --- |
| `ipa-dict` | US | open-dict-data/ipa-dict `en_US`, pinned revision | MIT |
| `britfone` | UK | Britfone 3.0.1, pinned revision | MIT |
| `wiktionary` | UK, US | Wiktionary rows labelled UK/RP or US/GA | CC BY-SA 4.0 |
| `wiktionary-untagged` | UK, US | Unlabelled Wiktionary rows assigned by phonetic markers | CC BY-SA 4.0 |
| `wiktionary-altspelling` | UK | British spellings (authorise, colour…) copied from the base spelling when the change is small | CC BY-SA 4.0 |
| `wiktionary-inflected` | UK | Regular plurals, -s, -ed, -ing, -er, -est derived from a UK base by RP suffix phonology, using Wiktionary's own form tables | CC BY-SA 4.0 |

The Wiktionary layers come from `scripts/resources/wiktionary-ipa.tsv` and
`wiktionary-forms.tsv`, extracted from the kaikki.org wiktextract dump by
`extract-wiktionary-ipa.py` and merged by `merge-wiktionary-ipa.py`. They only
fill words the first two layers lack; lookups return Britfone or ipa-dict first,
then the layers in the order above. Every UK row is checked against
`UKPhoneInventory` at build time and by
`ProductionPersistenceTests.bundledUKPronunciationsParseWithUKInventory`; UK rows
never contain rhotic codas or US-only symbols.

At runtime, words the database lacks are spelled out by eSpeak NG from the UK
Reference package (`UKG2P`, voices `en-gb` and `en-us`) during import and
backfill; those annotations carry the source `eSpeak NG … generated IPA` and are
never written into this file.

The script verifies source SHA-256 values, writes source/version provenance into
the `metadata` table and copies the required licence texts into this directory.
Re-run it only after intentionally updating the pinned revisions and checksums.
To refresh the Wiktionary layers, run `extract-wiktionary-ipa.py` on a new kaikki
dump, commit both TSVs and update their checksums in the build script.
