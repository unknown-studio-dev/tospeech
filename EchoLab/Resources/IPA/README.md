# Offline IPA dictionary artifact

`ipa.sqlite` is generated by `native/scripts/build-ipa-dictionary.sh` from the
pinned MIT-licensed ipa-dict US and Britfone UK source revisions. The app reads
this local SQLite resource only; it does not download a dictionary at runtime.

The script verifies source SHA-256 values, writes source/version provenance into
the database and copies the required license texts into this directory. Re-run it
only after intentionally updating the pinned source revisions and checksums.
